# Project Charter

## Project

Medicine Tracker

## Status

🟢 Planning

## Problem Statement

Люди часто не знают, какие лекарства уже находятся дома, в каком количестве они доступны и пригодны ли они к использованию.

Особенно это становится проблемой в ситуациях, когда лекарство необходимо купить срочно. Пользователь может потратить время на поездку домой для проверки аптечки или купить препарат повторно, не зная, что он уже есть дома.

Дополнительные сложности возникают из-за сроков годности, срока использования после вскрытия упаковки и необходимости отслеживать лекарства нескольких членов семьи.

## Goal

Разработать мобильное приложение для управления домашней аптечкой, которое позволит пользователю быстро узнать:

- какие лекарства есть дома;
- в каком количестве;
- где они находятся;
- до какого момента их можно использовать;
- кому они принадлежат;
- когда необходимо пополнить запас.

## Target Platforms

- Android
- iOS

## Target Users

Первоначальная целевая аудитория:

- семьи с детьми;
- люди, которые регулярно используют лекарства;
- пользователи, желающие организовать домашнюю аптечку.

## Core Value Proposition

Пользователь должен иметь возможность в любой момент быстро получить актуальную информацию о домашней аптечке и принять решение о необходимости покупки лекарства.

## Development Approach

MVP → Beta → Public Release

Разработка начинается с исследования проблемы и проектирования продукта.

После формирования требований и архитектуры начинается реализация MVP.

## Initial Scope

Первая версия продукта должна сфокусироваться на основной проблеме:

> Пользователь должен быстро понять, есть ли нужное лекарство дома.

Основные направления MVP:

- добавление лекарств;
- поиск и просмотр лекарств;
- количество и единицы измерения;
- срок годности;
- пользовательский срок использования после вскрытия;
- напоминания;
- фотографии лекарств;
- базовая семейная аптечка;
- локальное хранение данных.

Более сложные возможности будут оцениваться после формирования MVP.

## Future Scope

Возможные направления дальнейшего развития:

- OCR для автоматического распознавания информации с упаковки;
- проверка совместимости лекарств;
- облачная синхронизация;
- расширенная семейная аптечка;
- экспорт PDF;
- интеграция с аптеками;
- аналитика;
- подписка;
- AI-функции;
- интеграции со сторонними сервисами.

Наличие функции в Future Scope не означает, что она обязательно войдет в продукт.

## Non-Goals

Приложение не должно:

- заменять врача;
- самостоятельно ставить диагнозы;
- назначать лечение;
- принимать медицинские решения вместо пользователя или специалиста;
- предоставлять ложную уверенность в безопасности применения лекарства.

AI-функции, если они будут реализованы, должны рассматриваться как вспомогательный инструмент, а не как медицинский специалист.

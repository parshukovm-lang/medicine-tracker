Success Criteria
Проект считается успешным, если:
- опубликовано приложение для Android и iOS;
- пользователь может полностью управлять домашней аптечкой;
- приложение работает офлайн;
- данные синхронизируются между устройствами;
- первые пользователи используют приложение регулярно;
- кодовая база остается поддерживаемой и документированной.

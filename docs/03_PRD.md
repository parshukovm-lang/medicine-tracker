# 1. Product Overview

Medicine Tracker — мобильное приложение для управления домашней аптечкой.

Приложение должно позволять пользователю:

- знать, какие лекарства есть дома;
- видеть актуальное количество;
- учитывать несколько упаковок одного лекарства;
- учитывать разные сроки годности упаковок;
- учитывать срок использования лекарства после вскрытия;
- получать предупреждения о проблемах;
- быстро находить нужное лекарство;
- изменять остаток лекарства;
- сохранять историю изменений;
- выделять лекарства для быстрого доступа;
- управлять семейной аптечкой.

Основные платформы:

- Android
- iOS

Development approach:

MVP → Beta → Public Release

# 2. Problem Statement

Пользователь часто не знает точно, какие лекарства уже есть дома и в каком количестве.

Особенно проблема проявляется в ситуациях:

- когда врач назначил несколько лекарств;
- когда лекарство нужно купить срочно;
- когда дома могут находиться несколько упаковок одного препарата;
- когда упаковки имеют разные сроки годности;
- когда одна упаковка уже вскрыта;
- когда лекарство имеет ограниченный срок использования после вскрытия.

Типичный сценарий:

> Пользователь получает назначение врача и находится в аптеке. Он не уверен, есть ли нужное лекарство дома. Проверить это физически сложно, особенно если дома находится больной ребёнок.

Medicine Tracker должен дать пользователю возможность быстро ответить на вопрос:

> «Есть ли у меня дома нужное лекарство и сколько его осталось?»

---

# 3. Product Goal

Главная цель MVP:

> Сделать домашнюю аптечку понятной и актуальной цифровой копией реальных запасов лекарств пользователя.

Приложение должно минимизировать необходимость помнить:

- какие лекарства есть;
- сколько их осталось;
- в каких упаковках они находятся;
- когда истекает срок годности;
- какие упаковки уже вскрыты.

---

# 4. Target User

Основной пользователь:

Человек, который хранит дома несколько лекарств и хочет понимать состояние своей домашней аптечки.

Особое внимание уделяется:

- семьям;
- родителям;
- пользователям, которые регулярно покупают лекарства;
- пользователям, которые хотят быстро проверить наличие лекарства перед покупкой.

Интерфейс должен быть максимально понятным и не требовать от пользователя специальных знаний.

# 5. Core User Scenarios

## 5.1. Добавление лекарства

Пользователь покупает лекарство и хочет добавить его в аптечку.

Основной сценарий:

1. Пользователь нажимает «Добавить».
2. Начинает вводить название лекарства.
3. Приложение предлагает подходящие варианты.
4. Пользователь выбирает лекарство.
5. Пользователь выбирает дозировку.
6. Пользователь выбирает форму выпуска.
7. Приложение предлагает тип учета.
8. Пользователь при необходимости изменяет предложенный тип учета.
9. Пользователь вводит данные упаковки.
10. Пользователь добавляет упаковку в аптечку.
11. Пользователь возвращается на главный экран.
12. Добавленное лекарство становится видимым на главном экране.

После добавления пользователь должен визуально увидеть результат операции.

---

## 5.2. Добавление второй упаковки существующего лекарства

Если лекарство уже существует в аптечке:

1. Пользователь открывает карточку лекарства.
2. Нажимает «Добавить упаковку».
3. Вводит данные новой упаковки.
4. Новая упаковка добавляется к существующему лекарству.

Создавать новое лекарство для каждой новой упаковки не требуется.

Пример:

```text
Ибупрофен 200 мг

📦 Упаковка 1
5 таблеток
Срок: 01.10.2026

📦 Упаковка 2
20 таблеток
Срок: 01.03.2028
